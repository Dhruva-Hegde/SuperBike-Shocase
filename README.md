# 🏍️ SuperBike Showcase

A responsive static website designed to showcase high-performance superbikes with detailed specifications, clean UI, and interactive elements. This project demonstrates frontend development skills using core web technologies.

---

## 🚀 Features

* 📱 Fully responsive design for mobile, tablet, and desktop
* 🏍️ Showcase of multiple superbikes with structured layouts
* 🎨 Clean and modern UI with visually appealing sections
* ⚡ Interactive elements implemented using JavaScript
* 🧭 Easy navigation and user-friendly interface

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript

---
